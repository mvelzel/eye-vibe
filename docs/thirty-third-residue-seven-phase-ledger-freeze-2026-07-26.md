# Thirty-third pass — residue-seven phase-ledger freeze

## New executable relation

The synchronizing-bridge pass fixes a common phase length of 17 and complete
bridge lengths:

```text
message  bridge length  typed suffix
E4       20             3
W4       21             4
E5       20             3
```

Independently, factoradic unranking of the final headers gives the input that
maps to newline:

```text
message  header  newline preimage
E4       27      4
W4       77      3
E5       33      4
```

The earlier second marker row has directed cycle circulation:

```text
76 + 63 + 34 = 173 = 7 mod 83
```

The inspected relation is therefore:

```text
suffix length + newline preimage = row-2 circulation = 7
```

for all three final panels.

This was noticed after the bridge result. The audit below asks whether it is a
specific typed ledger under a generic header-assignment null. It is not a
prospective discovery p-value.

## Fixed objects

- canonical three marker rows and their first-two-digit edge coordinates;
- ordinary lexicographic unranking on the established six-symbol alphabet;
- symbol 5 as the already established newline symbol;
- final bridge endpoints, late entries, and three-way common-prefix length
  from the promoted synchronizing-bridge audit;
- suffix length `bridge_length - common_prefix_length`, with no adjustment;
- row-2 circulation as the ordinary mod-83 sum of its three directed header
  checks;
- the existing 12,096-assignment conditional universe: permute only the
  observed scalar multiset, keep edge coordinates fixed, retain nine distinct
  ranks in `0..82`.

No body label value, plaintext, language model, Gate number, or arbitrary
constant enters the primary test.

## Generic primary statistic

For each admissible scalar assignment:

1. reconstruct all nine header ranks;
2. compute `C = sum(row2 headers) mod 83`;
3. unrank each final header and find the input position of newline;
4. add that preimage to the fixed suffix length for the same panel;
5. accept only if all three sums equal `C`.

The constant is recomputed for every assignment. Thus the null does not merely
ask how often a fixed target seven appears.

Report:

- primary match count among 12,096 assignments;
- matches that also have final-row scalar-digit sum equal to `C`;
- which of the two unchanged full factoradic-header survivors match.

## Broad controls

Within every assignment, report these nested broadenings:

1. **any symbol:** replace newline by any one common symbol `0..5`;
2. **suffix permutation:** keep newline but assign the multiset `(3,3,4)` to
   final panels in any of its three distinct orders;
3. **symbol and suffix:** allow both menus;
4. **constant only:** ignore row 2 and ask whether some symbol gives the same
   preimage-plus-suffix sum in all three panels;
5. **constant plus suffix:** additionally allow the three suffix assignments.

The same symbol and one global suffix assignment must serve all three panels.
No per-panel symbol, sign, modulus, affine intercept, or alternate group
unranking is allowed.

Inventory all matching `(symbol, suffix assignment, constant)` triples for the
observation. This prevents a verbal interpretation from hiding alternative
readings.

## Positive and negative controls

Tests must:

- reproduce suffixes `(3,4,3)` from the canonical bridge coordinates and
  common phase, rather than hard-coding them into the observed assertion;
- recover the observed newline ledger and constant seven;
- fail the exact ledger after changing one final scalar assignment while
  retaining valid ranks;
- enumerate the existing 12,096 assignments and two factoradic survivors
  exactly.

## Promotion gate

Promote a body consumer for the row-2 residue and factoradic newline field only
if:

- the exact generic event is uncommon under the conditional universe;
- the any-symbol and symbol-plus-suffix counts remain selective;
- the observed assignment is distinguished among the two unchanged
  factoradic survivors.

The result may type the phase schedule. It cannot by itself identify what the
newline state means, decode body labels, or validate the Gate cache machine.
