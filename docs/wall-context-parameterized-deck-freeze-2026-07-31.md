## Reversible update catalog

Start from identity and reverse 83-card decks. For the selected card at current
rank `r` and source distance `d mod 83`, test:

1. move the selected card toward front by `d`;
2. swap the selected card with position `d`;
3. swap top with position `d`;
4. reverse the first `d+1` cards;
5. rotate the first `d+1` cards so position `d` becomes top;
6. rotate the full deck left by `d`.

Run both natural interpretations:

- Eye values are emitted card labels, so their label indexes the Wall table
  and decoded output is current rank;
- Eye values are rank instructions, so their rank indexes the Wall table and
  emitted output is the selected card label.

Every family must first round-trip a planted rank stream exactly.
