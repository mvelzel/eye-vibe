# Thirty-first pass — Gate `+3` marker-transfer freeze

## Motivation and evidential boundary

The later Gate/WAK audit independently supplied an exact operator:

```text
3
```

The current Noita WAK has the uniquely selected salt pair whose integer
parts map to `+3`, and Veska's authored lower band depicts a five-pixel plus
followed by three singleton marks.  Applying that exact operator to the Eye
marker grid exposes a new inspected relation:

```text
West4  77 + 3 = 80  West1
East5  33 + 3 = 36  East2
```

West4 and East5 are exactly the two non-self fields of the established final
anchor record.  East4 is its self/total field and does not transfer:

```text
East4  27 + 3 = 30  absent
```

The observation was made before this freeze, so its exact conditional count
is descriptive.  The purpose of this pass is to determine whether it is a
small marker-layer construction relation, a factoradic operation, or an
ordinary two-hit coincidence.

## Fixed data

- canonical message order and natural three marker rows;
- orthodox marker ranks modulo `83`;
- the already established control edge of each header;
- the final row's independently established role split:
  `East4` is self/total, `West4` and `East5` are the two non-self increments;
- exact operator `+3`, with no alternative sign, offset, digitwise repair,
  or affine intercept;
- ordinary lexicographic unranking of ranks as permutations of the existing
  six-symbol header alphabet;
- the existing 12,096-assignment conditional universe: keep all first two
  base-five coordinates fixed, permute only the observed third-digit
  multiset, retain in-range distinct ranks.

No body value, plaintext score, source text, or arbitrary key enters this
pass.

## Primary marker-transfer statistic

For the two fixed final non-self messages, add `3 mod 83` to the complete
rank.  Count how many results are members of the fixed first marker row.

The observed score is two of two.  Also report whether the final self/total
field transfers to any marker; its absence is a typed description, not an
additional multiplicative probability.

The exact conditional tail is the fraction of the 12,096 assignments with
the same two-of-two final-nonself-to-first-row score.  Because the event was
noticed first, do not call this a prospective p-value.

## Factoradic execution consequence

For each observed transfer `source -> source+3`, unrank both endpoints as
six-symbol permutations.  Compute both conventional quotients:

```text
left  = target * inverse(source)
right = inverse(source) * target
```

Test the unfitted consequence that the two transfers use the same left
quotient or the same right quotient.  Report the quotient, cycle structure,
order, and whether it belongs to the established first-row D4 group.

For every assignment in the conditional universe, perform the same test only
after the exact two-of-two transfer succeeds.  Count equality on each side.

## Broad correction and controls

The broad marker statistic retains the externally selected `+3`, but searches
all six ordered pairs of distinct natural marker rows.  For each source row,
use only its non-self fields and count transfers into the target row.  Record
the maximum hit count and maximum hit fraction; compare the observation
against both because the final row has two eligible fields while the first
two have three.

The broad factoradic statistic additionally allows:

- either left-quotient or right-quotient equality;
- every ordered row pair attaining the observed complete-transfer score.

Report how many conditional assignments contain any completely transferred
non-self source row and how many also give one shared factoradic quotient.

As an operator-selection diagnostic—not the primary null—enumerate all
nonzero shifts `1..82` on the observed marker grid and report which shifts
produce a complete transfer for any ordered row pair.  This discloses how
special `3` is among shifts; it may not replace the exact test because `+3`
came from a separate later asset.

## Calibration and stop rule

Unit tests must include:

1. the exact observed transfer;
2. a synthetic grid with a planted two-field `+3` transfer and shared
   quotient;
3. a negative grid with one broken target;
4. agreement between direct permutation composition and quotient recovery.

Promote only a narrow marker-machine link if the two transfers share an exact
factoradic operation and remain unusual after the broad conditional audit.
If transfer is common or the factoradic operations disagree, retain the
arithmetic pair as a curiosity and do not apply `+3` to Eye bodies.
