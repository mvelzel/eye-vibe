# Waite East-2 sparse ordinary-GAK audit — freeze

## Question

Can the exact 81-character Waite sentence already aligned to raw East 2
positions `37..117` be generated by one ordinary GAK deck cipher?

```text
SUBLIME THAT WHICH IS THE LOWEST, AND MAKE THAT WHICH IS THE HIGHEST, THE LOWEST.
```

The source was selected retrospectively. Its strongest prior support is a
20-character repeated passage whose two ciphertext windows have the same
equality pattern. This audit tests architectural feasibility, not source
discovery likelihood.

## Frozen architecture

- deck size: 83 cards, labelled by the orthodox trigram ranks;
- plaintext alphabet: the sentence's 20 literal characters, with spaces and
  punctuation retained and each distinct character selecting one operation;
- one arbitrary permutation of 83 deck positions per plaintext character;
- ordinary GAK update:

  ```text
  new_deck[i] = old_deck[operation[character][i]]
  output = new_deck[0]
  ```

- the East-2 suffix begins from an arbitrary deck state;
- no XGAK output selector, extra memory, postprocessor, normalization,
  character merging, source sliding, or alignment change.

The arbitrary state is quotiented by simultaneous relabelling of the 82
non-top positions. A symbolic initial top card and sorted remainder therefore
represent all possible starting decks without enumerating `83!` states.

## Frozen solver

The new encoding tracks inverse-deck positions rather than materializing every
deck after every character. If `q_c` is the inverse position permutation for
character `c`, then a card position evolves as:

```text
position_t(card) = q_c[position_(t-1)(card)]
```

The observed ciphertext card is constrained to position zero after each
update. For every pair of visited edges under the same character, their input
positions are equal if and only if their output positions are equal. This is
exactly functionality plus injectivity on the visited fragment of `q_c`. Any
such partial injection on a finite 83-element set extends to a complete
permutation; unvisited inputs and outputs are paired canonically when
extracting a witness. The result is then inverted back to the forward
convention and must replay the exact ciphertext.

## Calibration and stop rules

Before the real sentence is inspected, the solver must recover and replay:

1. a deterministic small-deck fixture;
2. a planted 83-card, 81-character fixture with the same plaintext and
   20-operation alphabet.

The planted Eye-scale fixture has a 60-second ceiling. If it is not decided,
the real result is only a solver limitation.

The real sentence receives one 60-second run. Outcomes mean:

- `unsat`: reject this exact Waite suffix under ordinary arbitrary-permutation
  GAK;
- `sat`: establish feasibility only, because the operation family has very
  high capacity;
- `unknown`: leave the hypothesis unresolved.

If the full sentence is SAT, fit the first 70 characters without changing any
setting and test whether the actual 71st ciphertext card is forced. Two
different satisfiable next cards are sufficient to demonstrate
non-identifiability; only exclusion of all 82 alternatives would count as a
held-out prediction.
